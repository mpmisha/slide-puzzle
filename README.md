# Slide Puzzle 🧩

A calm sliding-tile puzzle for kids — part of the [Playground](https://mpmisha.github.io/playground/) hub.

**Play:** https://mpmisha.github.io/slide-puzzle/

Slide the colourful tiles until the picture flows back into a clean rainbow. The
puzzles get **gently harder as you go** — starting with an easy 2×2 and working
up through 3×3 and 4×4, a little more shuffled each level. There's no timer and
no way to lose. No ads, no accounts, no internet needed after the first load.

## How to play

- **Slide a tile:** tap any tile in the same row or column as the empty gap and
  the whole line slides toward it (a big, forgiving target for little fingers).
- **Goal:** put every tile back so the colours make a smooth gradient again.
- **Getting harder:** each solved puzzle unlocks a slightly tougher one, and your
  progress is remembered. Clear all 12 for a victory — then it loops.
- **Stuck?** Turn on **Show numbers** in settings for a gentle hint on each tile.

## Difficulty design

Difficulty ramps along two axes — **grid size** (the big step: 2×2 → 3×3 → 4×4)
and **scramble depth** (the fine step: how far the board is shuffled from solved).
The ladder raises scramble depth first, then grid size, so the jump between
levels stays small.

Every puzzle is generated by starting from the **solved** board and applying a
number of random **legal** slides. This guarantees the puzzle is always solvable
(a random tile permutation would be unsolvable half the time — board parity) and
makes the scramble count a clean difficulty dial.

## Tech

Pure vanilla JavaScript (ES modules), an HTML canvas, and the Web Audio API — no
frameworks, no build step. It's a PWA: installable to the home screen and fully
playable offline via a service worker. It shares the Playground design system
(candy-block palette, twilight background, rounded panels, gentle sounds) and the
hub's global Sound/Vibration settings.

## Structure

```
index.html              # app shell + HUD + overlays
styles.css              # HUD, panels, toggles, overlays
manifest.webmanifest    # PWA manifest
service-worker.js       # offline cache
icons/                  # app icons (generated with PIL)
js/
  main.js               # DOM wiring (HUD, overlays, hub handshake)
  scene.js              # canvas renderer, tile animation, input, loop
  game.js               # rules & state (levels, progress)
  puzzle.js             # board model: solvable scramble + line slides
  levels.js             # the difficulty ladder
  textures.js           # glossy candy tile / board rendering
  skins.js, color.js    # shared palette + colour helpers
  audio.js              # Web Audio sound + haptics
  storage.js            # settings (shared) + progress (localStorage)
```
